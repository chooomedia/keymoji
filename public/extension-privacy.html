Keymoji Browser Extension Privacy Policy

Last updated: July 11, 2026

English

The Keymoji Browser Extension generates emoji passwords locally in your browser. It does not send generated Keymojis, passwords, password fields, website content, or browsing activity to Keymoji servers.

  • Generated Keymojis are created locally with the Web Crypto API.
  • Existing password field values are not read, logged, or stored.
  • Autofill only happens after an explicit user action.
  • The extension stores only local preferences such as level and prompt settings via browser extension storage.
  • No analytics, tracking cookies, account login, n8n workflow, or AI Story Mode backend is used by this extension MVP.

Contact: hello@keymoji.wtf

Deutsch

Die Keymoji Browser Extension erzeugt Emoji-Passwörter lokal in Ihrem Browser. Generierte Keymojis, Passwörter, Passwortfelder, Webseiteninhalte oder Browseraktivitäten werden nicht an Keymoji-Server übertragen.

  • Generierte Keymojis werden lokal mit der Web Crypto API erstellt.
  • Bestehende Passwortfeld-Werte werden nicht gelesen, protokolliert oder gespeichert.
  • Das Einsetzen erfolgt nur nach einer ausdrücklichen Nutzeraktion.
  • Die Extension speichert nur lokale Einstellungen wie Level und Prompt-Verhalten im Browser-Extension-Speicher.
  • Dieses Extension-MVP nutzt keine Analytics, keine Tracking-Cookies, keinen Account-Login, keine n8n Workflows und keinen AI Story Mode Backend-Aufruf.

Kontakt: hello@keymoji.wtf

Main website privacy policy: keymoji.wtf/privacy
